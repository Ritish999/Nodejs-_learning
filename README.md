## 🧠 What I've Learned

### 1. Node.js Fundamentals
- Understanding Node.js and its working environment
- Using `require()` and `module.exports`
- Working with npm and packages
- Managing environment variables using `.env`

### 2. Express.js
- Creating Express servers
- Understanding routes and route handlers
- Working with middleware
- Using `express.json()` and `express.urlencoded()`
- Handling HTTP requests and responses

### 3. REST API & CRUD Operations

Learning how to perform the four main CRUD operations:

| Operation | HTTP Method | Purpose |
|---|---|---|
| Create | POST | Create new data |
| Read | GET | Fetch existing data |
| Update | PATCH | Update existing data |
| Delete | DELETE | Remove data |

### 4. MongoDB & Mongoose
- Connecting Node.js with MongoDB
- Creating schemas and models
- Performing database operations
- Using methods like:
  - `Blog.create()`
  - `Blog.find()`
  - `Blog.findById()`
  - `Blog.findByIdAndUpdate()`
  - `Blog.findByIdAndDelete()`

### 5. File Uploads with Multer
- Understanding Multer middleware
- Configuring storage
- Handling image uploads using `req.file`
- Handling multipart/form-data
- Updating and deleting uploaded images

### 6. API Testing with Postman
- Sending GET, POST, PATCH and DELETE requests
- Testing API endpoints
- Working with JSON and form-data
- Handling API responses and status codes
